# FertiCare 360

AI-powered fertility, IVF, maternal and child health monitoring platform — clickable UI prototype built for an ideathon.

**From fertility to healthy childhood:** Woman Profile → Fertility Assessment → IVF Tracker → Pregnancy Monitoring → Birth Transition → Postnatal Care → Newborn Care → Child Growth.

## Live demo

After enabling GitHub Pages (steps below), the prototype is available at:

`https://<your-username>.github.io/<repo-name>/`

## Run locally

No install or build step needed. Download `index.html` and open it in Chrome (or any browser).

## Features

- Journey-based onboarding (Trying to Conceive, IVF, Pregnant, New Mother, Child Health)
- IVF stage tracker with medication and appointment reminders
- Pregnancy dashboard with weight tracking and warning symptoms
- Birth transition: profile moves to Mother + Baby care
- Postnatal wellness check-in, newborn feeding log, child milestone tracker
- AI Health Assistant (rule-based demo, decision support only)
- Maternal and child Health Risk Score (sample data)

## Deploy on GitHub Pages

1. Push these files to a GitHub repository (branch `main`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. Wait about a minute, then open the link shown on that page.

## Tech

React 18 (bundled inline), Babel standalone, plain CSS. Sample data only.

## Disclaimer

This prototype provides decision support only and does not replace a doctor or medical advice.
